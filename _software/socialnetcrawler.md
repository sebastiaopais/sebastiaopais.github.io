SocialNetCrawler is a desktop application, written in Java with a Swing interface, for collecting data from social networks. To use it, obtain an access token from the developer page of each supported network, enter it in the corresponding tab of the application and start crawling.

*Supported by project C4 - Cloud Computing Competences Centre, financed by Portugal 2020.*
